# Odin Recipes

A simple recipe website built as part of The Odin Project's Foundations course.

## About this project

This project is my first real HTML site — a collection of recipe pages
linked together. It's meant to practice the basics of structuring a
multi-page website before CSS and JavaScript get introduced.

## Skills demonstrated

- Writing semantic HTML and structuring a basic webpage
- Creating and linking multiple HTML pages
- Using relative file paths to link between pages and folders
- Organizing a project with a clear folder structure
- Using Git and GitHub for version control
